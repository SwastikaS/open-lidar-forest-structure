# Outputs

- `figures/`: static figures embedded in the main project README
- `tables/`: site-, grid- and crown-level measurements in CSV format
- `vectors/`: detected treetops and delineated crowns in GeoPackage format
- `rasters/`: generated CHM and multiband metric rasters; excluded from Git

Run `scripts/06_export_figures.R` after scripts 01–05 to reproduce the figures.
